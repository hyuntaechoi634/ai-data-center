# AI data-center outputs

The four-database runner writes generated products only below:

- `ai-data-center-databases/`
- `ai-data-center-run-logs/`
- `ai-data-center-database-backups/`

Each database group contains six scenarios. Run logs are permanent evidence
for the completion gate and should be reviewed before a database is treated
as complete. Generated databases and logs are ignored by Git.
